# CountMaster Blackjack Trainer

Free online blackjack card counting trainer focused on the Hi-Lo system.

## Features

- Hi-Lo card counting practice
- Multiple deck configurations
- Adjustable dealing speed
- True Count calculation
- Mobile and desktop support
- Advanced training mode
- Realistic blackjack flow

## Run Locally

### Install dependencies

npm install

### Start development server

npm run dev
